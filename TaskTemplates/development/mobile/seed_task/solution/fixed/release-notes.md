# Home

The home screen shows the system title, a freshness pill, saved commute stops, and current commute reminders. Favorite stations render as cards with bikes, docks, capacity, status, and a detail link.

# Search

Search matches station names and short codes. The result list stays in the same mobile flow, and each card links straight into the station detail route.

# Station Detail

The detail page shows station name, station code, bikes, docks, capacity, last report time, coordinates, and any station-specific reminder derived from the current station status.

# Re-entry Behavior

After the app has loaded once, the home page and previously opened station detail pages can be reopened when connectivity drops. The retained view is labeled with `Saved snapshot` so commuters can tell when the saved version is being shown.

# Quick Access

The install entry name is `BikeBoard`. Launching from the quick-access start URL opens the saved-stop workflow and shows the quick-access banner at the top of the screen.

# Data Freshness

The freshness pill is always visible in the header. It shows the latest known update time together with either `Current feed` or `Saved snapshot`.
