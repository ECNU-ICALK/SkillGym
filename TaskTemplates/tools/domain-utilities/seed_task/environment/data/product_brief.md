# Product Brief

Project slug: orbitops

## Product

OrbitOps is a developer workflow product for platform teams that need one place to track release readiness, handoff blockers, deploy windows, and service-level launch checks. The product should sound dependable, compact, and tool-like.

## Audience

- Platform engineering teams
- Release managers
- Developer productivity leads

## Naming preferences

- Prefer short compound names that can still be spoken clearly in meetings
- Favor names that suggest workflow, coordination, deployment, observability, or infrastructure support
- Keep base names between 8 and 12 characters
- Avoid hyphens and digits
- Keep at most one selected domain per base name in the final recommendation set

## Blocked terms

- cloud
- code
- bot
- app
- hub

## Launch constraints

- Use only the candidate base names provided for this round
- Use only the allowed TLDs from the policy file
- Provide 6 shortlisted domains and 2 runner-up domains
- Keep the final recommendation set aligned with a developer-tool audience
