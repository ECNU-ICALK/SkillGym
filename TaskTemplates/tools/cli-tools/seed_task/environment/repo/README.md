# airdesk

Minimal Python CLI project for Harbor task `cli-tools__airdesk-release-pack`.

## Commands

- `airdesk version --format json`
- `airdesk stats --format json`
- `airdesk airport <ident> --format json`
- `airdesk country <iso_country> --limit <n> --format json`

## Release path defaults

- data dir: `/app/data/ourairports`
- contract: `/app/data/contracts/release_contract.json`
- output dir: `/app/output/release`
