`<Link>` renders an anchor with client-side navigation behavior.

```tsx filename="app/example.tsx" switcher highlight={1}
<Link href="/reports">Reports</Link>
```

```jsx filename="app/example.jsx" switcher highlight={1}
<Link href="/reports">Reports</Link>
```

## Reference

### Props

| Prop | Example | Type | Required |
| --- | --- | --- | --- |
| `href` | `"/reports"` | `string` | Yes |
| `prefetch` | `{false}` | `boolean` | No |
