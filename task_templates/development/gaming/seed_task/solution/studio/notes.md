# Kanto Encounter Atlas Notes

Use the `Seed` controls to keep a deterministic scene or jump to a new one.  
Choose a `Zone` to switch among the six local encounter snapshots.  
`Preset` toggles a bundled parameter profile, while `Parameters` allows manual fine tuning.  
The current seed, zone, preset, slider values, and color choices stay in the page hash so the same scene can be reopened after a refresh.  
`Colors` adjusts the viewing palette for the current scene without changing the underlying encounter statistics.  
Use `Export Scene JSON` to write the current scene payload into the export panel and download a matching JSON file for handoff.  
The export includes sampled trail points taken from the live p5 scene, so the handoff stays aligned with the current zone and seed.
