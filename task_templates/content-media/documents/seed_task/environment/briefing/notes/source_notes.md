# Source Notes

Use these source references in the final packet when you populate the Source Notes section.

- World Bank country endpoint for Canada, Mexico, and the United States:
  https://api.worldbank.org/v2/country/USA;CAN;MEX?format=json&per_page=100
- World Bank population endpoint:
  https://api.worldbank.org/v2/country/USA;CAN;MEX/indicator/SP.POP.TOTL?format=json&per_page=20000
- World Bank GDP endpoint:
  https://api.worldbank.org/v2/country/USA;CAN;MEX/indicator/NY.GDP.MKTP.CD?format=json&per_page=20000
- Our World in Data annual CO2 emissions grapher CSV:
  https://ourworldindata.org/grapher/annual-co2-emissions-per-country.csv?v=1&csvType=full&useColumnShortNames=false
- Our World in Data electricity production by source grapher CSV:
  https://ourworldindata.org/grapher/electricity-prod-source-stacked.csv?v=1&csvType=full&useColumnShortNames=false

Country order for the packet: Canada, Mexico, United States.

Formatting notes:
- Population values should be shown in millions with one decimal place.
- GDP values should be shown in trillion current USD with two decimal places.
- CO2 values should be shown in megatonnes with one decimal place.
- Power-source labels should use title case, for example `Hydropower` and `Gas`.
