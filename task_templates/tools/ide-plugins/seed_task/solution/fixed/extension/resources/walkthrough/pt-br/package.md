# Empacote a extensão para distribuição

Confirme que `Explorador de Resumos de Atualização` segue em um único pacote VSIX com seus recursos localizados.

- Gere o artefato VSIX depois de revisar os resumos exportados.
- Verifique se a extensão empacotada ainda contém os arquivos de walkthrough e os bundles de runtime.
