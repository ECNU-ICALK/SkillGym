# Promises and Async/Await

Promises let you model work that finishes later without nesting callbacks by hand.
`async` and `await` make the same flow easier to read once you understand how Promise chaining works.

## Why this page exists

Use this page when you need a short refresher on Promise states, chaining, error propagation, and how `await` reshapes those flows at call sites.
