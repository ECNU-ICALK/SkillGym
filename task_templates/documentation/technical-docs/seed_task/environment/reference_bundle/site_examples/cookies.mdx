`cookies` reads request cookies in a server context.

```tsx filename="app/example.tsx" switcher highlight={3}
import {cookies} from 'next/headers'

const store = await cookies()
const theme = store.get('theme')
```

```jsx filename="app/example.jsx" switcher highlight={3}
import {cookies} from 'next/headers'

const store = await cookies()
const theme = store.get('theme')
```

## Reference

### Methods

| Method | Returns | Description |
| --- | --- | --- |
| `.get(name)` | `Cookie \| undefined` | Reads a cookie by name. |
| `.set(name, value)` | `void` | Writes a cookie value. |

## Good to know

- Call `cookies` where request data is available.
- Await the function before reading values.
